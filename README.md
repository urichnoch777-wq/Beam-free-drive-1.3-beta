# Beam Free Drive (BFR)

Открытая мобильная песочница с физикой мягких тел на **Godot 4** (GL Compatibility, под слабые телефоны).

## Запуск
1. Установи Godot 4.2+ → *Import* → выбери `project.godot` → **F5**.
2. Android: *Project → Export → Android* (нужен Android SDK по гайду Godot).

## Меню
Играть / Настройки. В настройках: управление **Стрелки / Руль / Наклон**. В игре камеру можно вращать пальцем (свободная зона экрана).

## Управление
| Действие | Клавиатура | Телефон |
|---|---|---|
| Газ / тормоз (назад) | W / S | GAS / BRAKE |
| Руль | A / D | свайп влево-вправо по левой половине экрана |
| Ручник | Space | HB |
| Респаун | R | RESET |
| Замедление 1× → 0.01× | T | SLOW |
| Антибуксовка вкл/выкл | Y | — |

## Что уже работает (v0.1)
- Мягкое тело: узлы + балки, пластическая деформация, разрыв балок, столкновения (`scripts/soft_body.gd`, `world.gd`)
- Кузов мнётся в реальном времени, стёкла бьются, зоны смятия спереди/сзади
- Подвеска (пружина, амортизатор, стабилизатор, ограничитель хода), шины с проскальзыванием
- Двигатель с кривой момента, турбо, автоматическая КПП, задний привод
- Радиатор: сильный лобовой удар → утечка → перегрев → двигатель глохнет
- Полигон: стена для краш-теста, трамплин, коробки; камера сзади; сенсорное управление

## План (см. 30 пунктов проекта)
Отрыв колёс и деталей, топливо и пожар, давление шин и проколы, ручная КПП со сцеплением,
дифференциалы и полный привод, покрытия (лёд/грязь/песок), вода, звук, фары и зеркала,
гараж/тюнинг, режимы игры (трафик, полиция, гонки), фоторежим, мультиплеер,
перенос решателя в GDExtension (C++) для скорости на старых телефонах.

## Сборка APK
Автоматически на GitHub: залей проект → вкладка **Actions** → *Build Android APK* → **Run workflow**.
Через несколько минут в запуске появится артефакт `beam-free-drive-apk` (debug APK, ставится на телефон напрямую).
Локально: Godot → *Project → Export → Android → Export Project* (нужны export templates и Android SDK).
